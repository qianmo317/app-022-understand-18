# 一个字从输入到印在纸上 —— 全链路代码通读

> 涉及代码：
> - 录入/过滤：`src/lib/input.ts`、`src/pages/Home.tsx`、`src/pages/Editor.tsx`
> - 拆格/排版：`src/lib/layout.ts`、`src/types.ts`
> - 绘制：`src/components/paint.tsx`、`src/components/PageView.tsx`
> - 预览/打印：`src/pages/Editor.tsx`、`src/pages/PrintView.tsx`、`src/styles.css`
> - 导出：`src/lib/exportImage.tsx`
> - 笔顺数据：`src/lib/data.ts`
>
> 主线一句话：**文本 → `parseInput` 过滤去重（→ 可选按笔画排序）→ 存入 `Worksheet.chars` → `paginate` 里逐字 `buildBlock` 拆成小格、贪心换行、按行数切页 → `RowContent` 把小格画成 SVG → `PageView`（预览/打印）或 `pageSvgMarkup`（导出 SVG/PNG）消费同一份 `pages`。**

## 0. 数据模型（贯穿全链路的字段）

`src/types.ts`：

| 类型 | 字段 | 含义 |
|---|---|---|
| `Layout` | `grid` | 格线：`tian`/`mi`/`huigong`/`square`/`line` |
| | `perLine` / `lines` | 每行格数上限 / 每页行数上限 |
| | `cellMm` / `lineGapMm` | 格宽 mm / 行距 mm |
| | `mix: {model, strokeSteps, trace, blank}` | 每字四种小格的配置数量 |
| | `show` / `traceColor` / `fourLine` | 信息带开关 / 描红颜色 / 拼音四线格 |
| `Cell` | `kind: 'model'|'step'|'trace'|'blank'`，`stepK?` | 一个小格；`step` 格带笔画序号 |
| `Block` | `{ char, cells: Cell[] }` | 一个字拆出的小格组合，**必须同行同页** |
| `Row` | `Block[]` | 一行 |
| `Page` | `Row[]` | 一页 |
| `Worksheet` | `chars: string[]`、`layout`、`pinyinChoice`、`sortByStrokes`、`pages` | 持久化的字帖文档 |

转换链：`string`（原始文本）→ `string[]`（去重后的字）→ `Block`（每字）→ `Row[]`（行）→ `Page[]`（页）→ SVG/DOM（图）。

## 1. 文字录入：原始文本从哪进来

两个入口，都调同一个 `parseInput`：

1. **首页新建**（`Home.tsx:18`）：`const preview = parseInput(text, { sortByStrokes, strokeCountOf })`，每次按键实时算。点「生成字帖」时若结果为空直接报错「请至少输入一个汉字、字母或数字」（`Home.tsx:22`），空内容不能建帖；非空才写入 `Worksheet.chars` 并跳转编辑器。
2. **编辑器原文输入框**（`Editor.tsx` 的 `onTextChange`，179–184 行）：`setText(v)` 保留原文显示，同时 `setWs` 把 `parseInput(v, …)` 的结果写回 `ws.chars`。输入框显示的是 `ws.chars.join(' ')`（进入编辑器时用空格拼回，102 行），所以**原文里的标点/空白只活在当前会话的 textarea 里，从不持久化**，保存的只有过滤后的字数组。

另外两个改字入口：
- 「替换为…」`doReplace`（189–208）：只取替换框第一个码元 `[...replaceText][0]`，替换后**重新跑一遍 Set 去重**（可能缩短数组），并同步 textarea。
- 「删除该字」`doDelete`：按字符过滤，同步 textarea。

## 2. 过滤与去重：`parseInput`（`src/lib/input.ts`）

### 2.1 输入输出

- 输入：`text: string` + `opts: { sortByStrokes?, strokeCountOf? }`
- 输出：`string[]`，去重后的字序列。

### 2.2 三步处理

```ts
const CJK_RE  = /[㐀-鿿]/;                 // U+3400–U+9FFF：扩展A + 基本区
const VALID_RE = /[㐀-鿿A-Za-z0-9]/;        // 汉字 + 英文字母 + 阿拉伯数字

const valid = [...text].filter((ch) => VALID_RE.test(ch));   // ① 码元展开 + 白名单过滤
// ② Set 去重，保留首次出现顺序
// ③ 可选：按笔画数排序
```

1. **过滤**：`[...text]` 按码元（code point，不是 UTF-16 码元）展开，能正确处理代理对；再用白名单正则逐个 `test`。中文标点（`，。！`）、空白（空格/制表/换行）、emoji、`㊙` 之类符号全部丢弃。有单测：`'a，b。c！3 4\t\n好！' → ['a','b','c','3','4','好']`。
2. **去重**：`Set` 记录已见，只 push 第一次出现的字。`'春天花 会花春' → ['春','天','花','会']`。顺序语义是「首次出现顺序」，后面重复出现不提前。
3. **按笔画数排序**（仅当 `sortByStrokes && strokeCountOf` 都给了）：
   ```ts
   out.sort((a, b) => (ca ?? Infinity) - (cb ?? Infinity));
   ```
   取数来自 `data.strokeCountOf`（即内置/自定义笔顺数据的条数）；**查不到笔顺的字笔画数按 `Infinity`，统一沉到末尾**。`Array.prototype.sort` 稳定，无数据字之间、同笔画字之间保持原顺序。单测：`中国人㐀 → 人(2) 中(4) 国(8) 㐀(无)`。

### 2.3 `isCjk`

`CJK_RE.test(ch)`，U+3400–U+9FFF 才算汉字。这是后面「无笔顺数据的汉字」分支的判定依据，字母数字永远不算。

### 2.4 边界与易踩点

- **CJK 白名单只到 U+9FFF**：B 扩展及以后的生僻字（U+20000+，如 𠀀）虽然 `[...text]` 能正确展开为一个码元，但**会被正则直接过滤掉**，连「无笔顺数据」标注的机会都没有。U+3400–U+4DBF 的扩展 A 字（如测试用的 `㐀`）保留，且可被识别为 CJK。
- 大小写字母、不同数字各自独立去重（`A`≠`a`）。
- 编辑器里排序开关切换时会用当前 textarea 原文重新 `parseInput`，所以排序是可逆地重算，不是对已排序数组再排。
- 去重发生在**字元层**，不做任何异体字/繁简归并。

## 3. 一个字为什么被拆成若干小格：`buildBlock`（`layout.ts:68`）

### 3.1 为什么拆

教学法要求：一个字不是只出现一次，而是按「**看例字 → 跟着笔顺分解逐笔写 → 描红 → 临写空格**」的练习序列重复出现。每个小格 100×100 units，里面放同一个字的不同形态。`mix` 四个配置控制每种格出几个。

### 3.2 输入输出与参与字段

- 输入：`char`、已 clamp 的 `Layout`（用 `mix.*` 与 `perLine`）、`strokeCount: number | undefined`（`getStrokes(ch)?.length`，无数据为 `undefined`）。
- 输出：`Block { char, cells }`。

### 3.3 拼接顺序与分支条件

```ts
const noStrokeHanzi = strokeCount == null && isCjk(char);
if (mix.model > 0) cells.push({ kind: 'model' });                       // ① 例字（最多 1）
if (mix.strokeSteps > 0 && strokeCount != null) {                       // ② 笔顺分解
  const n = Math.min(mix.strokeSteps, strokeCount);
  for (let k = 1; k <= n; k++) cells.push({ kind: 'step', stepK: k });
}
if (!noStrokeHanzi) {                                                   // ③ 描红
  for (let i = 0; i < mix.trace; i++) cells.push({ kind: 'trace' });
}
for (let i = 0; i < mix.blank; i++) cells.push({ kind: 'blank' });      // ④ 临写空格
return { char, cells: cells.slice(0, Math.max(1, layout.perLine)) };    // ⑤ 截断兜底
```

个数与顺序的决定规则：

| 小格 | 个数 | 顺序 | 生成条件 |
|---|---|---|---|
| `model` 例字 | `model`（clamp 后 0 或 1） | 永远最前 | `mix.model > 0` |
| `step` 笔顺分解 | `min(mix.strokeSteps, 实际笔画数)` | 紧随例字，`stepK = 1..n` | `mix.strokeSteps > 0` **且** `strokeCount != null` |
| `trace` 描红 | `mix.trace` | 分解之后 | **不是**「无笔顺数据的汉字」 |
| `blank` 空格 | `mix.blank` | 永远最后 | 无条件 |

默认配置 `{model:1, strokeSteps:3, trace:2, blank:4}`，一个 5 画的有数据字（如「永」）→ `[model, step1, step2, step3, trace, trace, blank×4]` 共 10 格；1 画的「一」→ step 只有 1 个，共 8 格。

### 3.4 不能破的约束

1. **块宽不得超过一行格数**：最后 `slice(0, max(1, perLine))`。这是硬兜底——即便把 mix 配成 1+8+8+8=25 格，块也只保留前 `perLine` 格，保证「一个字的组合永远放得进一行」，分页算法因此不需要处理「单块超行宽」。
2. **一个块不拆行、不拆页**：由 `paginate` 的贪心保证（见第 5 节），`Block` 在数据结构上就是不可拆单元。
3. 截断是**按顺序砍尾巴**：先砍 blank，再砍 trace、step，model 最先保留。被砍掉的格直接不存在，而不是挤到下一行。

### 3.5 易踩边界

- **一个字的组合比一整行还宽**：不会报错、不会溢出——先被 `slice` 静默截断到 `perLine`，因此可能出现「配了 8 个空格实际一个都没有」的情况，UI 上没有提示。
- 反过来说，分页时不会出现「单块放不下当前行就再开一行还是放不下」的死局，因为块宽 ≤ `perLine` 在构块时已成立。
- 极端配置 `mix` 全 0：`cells` 为空数组（slice 下限只作用于参数 `perLine`，不会补格）。该字仍在 `chars` 与块序列里（占一个 `Block`、参与换行判断，但 `used += 0`），可被点击选中，只是纸上什么都不画。

## 4. 每行格数 / 每页行数的上限怎么算（`layout.ts`）

### 4.1 A4 几何常量

```
PAGE: 210×297mm；左右边距各 5mm，上下各 8mm；页眉 headerMm = 12
usableWMm    = 210 - 5 - 5 = 200        // 行可用宽
rowsAreaHMm  = 297 - 8 - 8 - 12 = 269   // 行区可用高
```

### 4.2 行高为什么是格宽的 1.2 倍

`paint.tsx`：格体 100 units，上方信息带 `INFO_H = 20`（拼音/部首/笔画/结构），整行 `ROW_H = 120`，故 `ROW_FACTOR = 1.2`。1 unit = `cellMm/100` mm，所以**物理行高 = `cellMm × 1.2`**（格近似正方形，信息带挤占的是行与行之间的高度预算）。

### 4.3 两个上限函数

```ts
maxPerLine(cellMm) = max(1, floor(200 / cellMm))
maxLines(cellMm, gapMm) = max(1, floor(269 / (cellMm * 1.2 + lineGapMm)))
```

- 默认 20mm 格：每行 `floor(200/20) = 10` 格；行距 2mm 时行节距 = 24+2 = 26mm，每页 `floor(269/26) = 10` 行。
- 35mm 格 + 0 行距：`floor(269/42) = 6` 行（单测锁定）。

### 4.4 `clampLayout`：所有配置进排版前先修正

```ts
cellMm     ∈ [12, 35]（四舍五入）
lineGapMm  ∈ [0, 12]
perLine    ∈ [1, maxPerLine(cellMm)]       // 上界用修正后的 cellMm 算
lines      ∈ [1, maxLines(cellMm, gap)]
mix.*      ∈ [0, 8]，model ∈ [0,1]
```

- 注意 `perLine`/`lines` 是**用户可填的「每行格数/每页行数」**，几何上界由格宽反推；填超了静默夹回。`Math.round` 对 `NaN` 返回 `NaN`，但 `Math.max/min` 会把它夹成边界值，所以脏数据最终也落回合法整数。
- UI 的数字框 min/max 只是提示（`Editor.tsx:303-305`），真正的约束在 clamp；`updateLayout` 每次改配置都先过一遍 clamp 再存。
- `grid`、`show`、`traceColor`、`fourLine` 不在 clamp 范围内（联合类型/布尔/颜色串）。

### 4.5 易踩点

- `perLine` 被几何上界夹小后，已经过宽的块会在 `buildBlock` 的 slice 处被二次收窄——两处约束是串联的。
- 行距增大、格宽增大都会让每页行数变少；`lines` 夹取依赖这两个**已修正**的值。
- 页眉固定占 12mm、页脚（`.sheet-footer`）在布局高度之外只占 CSS 流式空间，高度预算里没有为页脚留 mm（页脚靠下边距区放置）。

## 5. 换行与换页：`paginate`（`layout.ts:89`）

### 5.1 输入输出

- 输入：`chars: string[]`、原始 `layout`、`strokeCountOf`（实时查笔顺条数，所以**导入新笔顺数据后重算分页，块宽可能变化**——step 格数变了）。
- 内部先 `clampLayout`，输出 `Page[]`。

### 5.2 贪心成行（换行发生在这里）

```ts
let current: Row = [];
let used = 0;
for (const ch of chars) {
  const block = buildBlock(ch, clamped, strokeCountOf(ch));
  if (used > 0 && used + block.cells.length > clamped.perLine) {
    rows.push(current);          // 放不下：先封行
    current = [block];           // 新行以本字开头
    used = block.cells.length;
  } else {
    current.push(block);         // 放得下（或当前行为空）：塞入
    used += block.cells.length;
  }
}
if (current.length > 0) rows.push(current);
```

要点：

- 换行判定是**整块宽度**相加与 `perLine` 比较，不是按字数。不同字因笔画数/有无数据，块宽不同（8 格、10 格……），每行字数因此可变。
- 判定条件带 `used > 0`：**行首的块无条件放入**。又因为块宽 ≤ `perLine`（构块兜底），所以行首永远放得下，不存在死循环/超宽行。
- 放不下只在**字与字之间**断，一个字的小格绝不跨行（不拆字）。
- 没有「两端对齐/拉伸」，行尾空位就空着。

### 5.3 切页（换页发生在这里）

```ts
for (let i = 0; i < rows.length; i += clamped.lines)
  pages.push(rows.slice(i, i + clamped.lines));
if (pages.length === 0) pages.push([]);
```

- 行先全部排好，再每 `lines` 行切一刀。**一行不跨页**（整行划入某页），页内行数 ≤ `lines`。
- 换页不看内容高度，只看行数；行数上界已由 `maxLines` 保证物理高度放得下，所以这里可以无脑切。
- 顺序完全保持 `chars` 顺序（测试验证 100 字展平后与输入严格相等）。
- **空内容 → 也返回一页 `[[]]`**：一张只有页眉/格子背景的空白字帖可直接打印。注意空数组的根源在 `chars` 为空；首页禁止建空帖，但编辑器里删光所有字是允许的，此时预览/保存都落到这个分支。

### 5.4 典型边界（有单测）

- 100 字 × 每块 10 格、每行 10 格、每页 10 行 ⇒ 恰好 10 页。
- 混合块宽：`一`（1 画，块宽 8）放第一行；`人/八`（2 画，块宽 10）作为第二、三个字时，`8+10 > 10` 各自另起一行，结果 3 行同页：`[['一'],['人'],['八']]`。即「一个字的块加上当前行比整行宽」时在**该字之前换行**。
- `pages` 是每次渲染/导出时现算的纯函数结果，`Worksheet.pages` 字段只是自动保存时记下的缓存页数（`Editor.tsx:125`），首页列表显示用，不参与排版。

## 6. 画成图：`RowContent` 与小格形态（`paint.tsx`）

坐标系：每格 100×100 units，格顶在 y=`INFO_H(20)`；一行 SVG `viewBox="0 0 perLine*100 120"`。`RowContent` 顺序遍历块、块内遍历 cell，x 每格 +100：

1. 每个 cell 先画 `GridLines`（田/米/回宫/方格/横线/拼音四线，`grid=line` 时还看 `fourLine`）。
2. 按 `kind` 画内容：
   - `model`：`GlyphAt` 完整字形（黑）+ `CellInfo` 信息带（拼音、部首·笔画·结构，受 `show` 开关控制）。**信息带只挂在例字格上方**。
   - `step`：`GlyphAt upto=k`——只画前 k 笔，已画笔画灰、当前第 k 笔加粗加深黑；右上角标数字 `k`。
   - `trace`：完整字形，描边色用 `layout.traceColor`、笔画更粗（`TRACE_W=62`）。
   - `blank`：只留格线。
3. 预览下选中字整块套蓝框（`selectedChar`），`plain` 模式（打印/导出）不画。

`GlyphAt` 的字形二分：

- `getStrokes(ch)` 有数据：用笔顺 SVG path 经 `glyphTransform`（1024 em 数据坐标 → unit 坐标）画出，`upto` 控制逐笔。
- 无数据：退化成 `<text>` 字体渲染（汉字字号 82、字母数字 64），带 `data-fallback="font"` 标记——**不伪造笔画**。

## 7. 预览与打印：`PageView`（`PageView.tsx`）

- `PageView` 内部自己 `clampLayout` + `paginate(worksheet.chars, layout, strokeCountOf)` 现算全部页，再逐页渲染 `.sheet`（210×297mm div，内联 mm 边距）。
- 每页：页眉（标题；**仅第 1 页（`pi === 0`）额外渲染 100mm 校验尺 `Ruler`**）+ 若干行 SVG（行宽 `perLine*cellMm` mm、行高 `cellMm*1.2` mm，行间用 flex `gap: lineGapMm`）+ 页脚「第 N 页 / 共 M 页」。
- 预览（`Editor.tsx:382`）：`<PageView worksheet onSelectChar>` 可点行选字（点击坐标经 `blockRanges` 命中块），外层只做 CSS `transform: scale()` 缩放，不改内容。
- 打印（`PrintView.tsx`）：同一个 `<PageView plain>`，没有第二套渲染。`styles.css` 的 `@media print`：`@page { size: A4 portrait; margin: 0 }`，`.sheet { page-break-after: always }`（最后一页 auto）。`?autoprint=1` 时等 `document.fonts.ready` 再延迟 300ms 调 `window.print()`，避免字体没加载完就出图。提示用户关「缩放/适应页面」，配合首页校验尺保证 1:1。

## 8. 导出整页图：为什么与预览是「同一份」（`exportImage.tsx`）

### 8.1 同一份的含义

导出走的也是 **同一组纯函数与同一绘制原语**：

```ts
const layout = clampLayout(worksheet.layout);
const pages  = paginate(worksheet.chars, layout, strokeCountOf);   // 与 PageView 完全相同的入参/算法
… renderToStaticMarkup(<RowContent row layout pinyinFor />)        // 与预览同一个组件
```

差异只在「外壳怎么包」：

| | 预览/打印 | 导出 |
|---|---|---|
| 页结构 | HTML div `.sheet` + 每行一个内联 `<svg>` | 单张整页 `<svg>`，每行包进 `<g transform="translate(x y) scale(scale)">` |
| 行内内容 | `RowContent` | **同一个** `RowContent`（服务端渲染成静态标记） |
| 页眉 | 标题 div + 第 1 页校验尺 | 标题 `<text>` + 右上「第 N 页 / 共 M 页」；**无校验尺** |
| 选中态/点击 | 预览有，打印 `plain` 无 | 无（不传 `selectedChar`） |

所以「图为什么是同一份」：分页数据由同一个 `paginate` 决定（页数、每行放哪些块、每块几格完全一致），格子与字形由同一个 `RowContent`/`GlyphAt` 画出；导出不是重新实现的渲染器，只是把同样的 SVG 原语序列化进独立 XML。

### 8.2 尺寸与坐标

`PX_MM = 96/25.4`（CSS 参考像素）。SVG 标签 `width="210mm" height="297mm"`，`viewBox` 用像素值（A4 ≈ 794×1123）；行组缩放 `scale = cellMm*PX_MM/100`，把 100 units 的格映射到 `cellMm` 物理宽；行 y 起始于上边距+页眉，逐行累加「行高 + gap」。标题做了 XML 转义（`escapeXml`），字体串手工去掉引号以免破坏属性。

### 8.3 SVG / PNG

- `exportSvg`：`pageSvgMarkup` 的字符串直接存成 Blob 下载，文件名 `{标题}-第{n}页.svg`（标题里的 `\/:*?"<>|` 替换成 `_`，空标题回退「字帖」）。
- `exportPng(ws, page, scale=4)`：同一份 markup → Blob URL → `Image` 加载 → 白底 canvas `drawImage` → `toBlob` 下载，输出约 3175×4490 px。**PNG 是 SVG 的栅格化快照**，内容同源；SVG 加载失败/无 2d context/编码失败分别 reject。

### 8.4 页码越界处理（重点边界）

```ts
const pi = Math.max(0, Math.min(pageIndex, pages.length - 1));
```

- 负页码 → 夹到第 0 页；超过末页 → 夹到最后一页。导出函数自身永不取到 `undefined` 行。
- 编辑器侧还有第二道保险：页码下拉的 `exportPage` 在页数变化时 `setExportPage(p => Math.min(p, max(0, pageCount-1)))`（`Editor.tsx:137-139`），例如删字导致页数减少时自动收回。
- 但文件名用的是调用方传入的原始 `pageIndex + 1`，而 SVG 内页脚用的是夹取后的 `pi + 1`——传越界页码时会出现**文件名页码与图内页脚不一致**（边缘调用才会碰到，UI 正常路径下拉项不会越界）。

### 8.5 其他导出边界

- 空内容：`paginate` 返回 `[[]]`，导出第 0 页得到仅含白底/页眉/页码的整页 SVG/PNG，不报错。
- PNG 中字体回退字（无笔顺汉字/字母）依赖运行环境字体；SVG 内嵌的是文字不是路径，换机器打开可能换字体（笔顺 path 字不受影响）。
- 每次点导出都重新 `paginate`，因此导出瞬间的 `worksheet`（含已导入的自定义笔顺）即所见内容。

## 9. 没有笔顺数据的汉字：全链路上的一致策略

判定核心：`getStrokes(ch)`（`data.ts`，内置 `strokes.json` + localStorage 自定义数据，空 strokes 数组也视为无）返回 `undefined`。

在四个环节分别被区别对待，原则是**不伪造笔画、但保留这个字**：

1. **排序**（`input.ts`）：笔画数按 `Infinity`，沉到排序末尾。
2. **拆格**（`buildBlock`）：`noStrokeHanzi = strokeCount == null && isCjk(char)` 为真时——
   - 不生成任何 `step` 分解格（条件 `strokeCount != null` 不满足）；
   - 不生成 `trace` 描红格（描红需要可描的笔画路径，用字体轮廓描红等于误教）；
   - **保留 `model` 例字与 `blank` 空格**。默认配置下块宽 = 1 + 4 = 5 格（单测锁定）。
3. **绘制**（`paint.tsx`）：
   - 例字格的字形走 `<text>` 字体回退，标 `data-fallback="font"`；
   - 例字格信息带：只有 `strokes || !isCjk(char)` 才挂拼音/部首等——**无数据汉字不挂常规信息带**，改为在格体内底部用红字明确标注 **「无笔顺数据」**（`data-no-stroke="1"`）。
   - 「N 画」信息只在 `strokes` 存在时出现。
4. **分页**：块宽变小（5 格 vs 10 格），自然影响换行；不需要专门分支。

对比：**字母数字**无笔顺但 `isCjk` 为假——不标红字、不享受「无汉字数据」豁免，`trace` 格照常生成（用字体字形做描红），信息带照常走（拼音通常无）。

补救路径：编辑器「导入笔顺数据」→ `importStrokes`（支持 `{chars:{...}}` 全量包 / `{字:{strokes}}` 映射 / `{strokes}` 绑定当前选中字三种形态；只接受非空 strokes 数组；写 localStorage）后，因 `PageView` 的 `key={v${dataVer}}` 重挂载与导出时现算，重算后该字立即转为正常块（分解/描红出现、红字消失）。

## 10. 边界条件速查表

| 场景 | 发生环节 | 行为 |
|---|---|---|
| 空文本 | 首页建帖 | 拦截报错，不建帖 |
| 字被删光（`chars=[]`） | 编辑器/分页 | `paginate` 返回 `[[]]`，渲染/打印/导出一张空白页；自动保存照常 |
| 标点/空白/emoji/U+20000+ 生僻字 | `parseInput` 过滤 | 直接丢弃，不占格不提示 |
| 重复字 | `parseInput` 去重 | 保留首次出现；替换字撞重时二次去重 |
| 单字块配置宽于一行 | `buildBlock` | `slice(0, perLine)` 静默截尾，永不超行、不拆字 |
| `mix` 全 0 | `buildBlock` | 空块，占字序不画格 |
| 行内放不下下一个字 | `paginate` 成组 | 在该字前换行；行首块无条件放入 |
| 行数超过每页上限 | `paginate` 切页 | 整行切到下一页，行不跨页 |
| `perLine/lines` 填超几何上限 | `clampLayout` | 夹到 `floor` 上限；格宽 12–35、行距 0–12、mix 0–8 |
| 无笔顺汉字 | 拆格/绘制 | 无 step、无 trace；字体回退 + 红字「无笔顺数据」；排序沉底 |
| 导入笔顺后 | 全链路重算 | 块宽/页数可能变化，标注消失 |
| 导出页码为负/超大 | `exportImage` | 夹到 `[0, n-1]`（UI 下拉还有一道收缩）；文件名用原始页码、页脚用夹取页码 |
| PNG 导出 | 画布/加载 | SVG 加载失败、无 2d context、toBlob 空均 reject；正常为 4× A4 位图 |
| 校验尺 | 预览/打印 vs 导出 | 仅整份文档第 1 页 DOM 有；导出 SVG/PNG 不含（README 称「每页」是文档已知出入） |
| 打印缩放 | 浏览器侧 | `@page A4 margin:0` + 100mm 尺，要求用户关「适应页面」，代码无法强制 |

## 11. 一页端到端走查（默认配置，输入「春天 春」）

1. `parseInput`：过滤空格、去重 → `['春','天']`（假设均有笔顺、均 9 画）。
2. `Worksheet.chars = ['春','天']`，layout 经 clamp：20mm、每行 10、每页 10、mix 1/3/2/4。
3. `paginate`：每字 `buildBlock` → 各 10 格 `[m,s1,s2,s3,t,t,b,b,b,b]`。第一字 used=10；第二字 10+10>10 → 封行、另起一行。2 行 ≤ 10 → 1 页 `[[春块],[天块]]`。
4. `PageView`：一张 210×297mm `.sheet`，页眉含标题与校验尺；两行 SVG（各宽 200mm、高 24mm），`RowContent` 画格线、例字+拼音信息带、3 个逐笔分解、2 个灰红描红、4 个空格；页脚「第 1 页 / 共 1 页」。
5. 打印：同一 DOM，`@page A4 margin:0` 分页输出。
6. 导出：`paginate` 重算出同样的 2 行，`RowContent` 静态标记塞进一张 210×297mm SVG；PNG 再把它栅格化 4 倍——预览看到什么，导出的图就是什么。
